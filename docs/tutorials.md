# Pixl Studio video tutorials

Seven short narrated videos, each under two and a half minutes, that walk through Pixl Studio
one thing at a time. Watch them embedded on the
**[tutorials page](https://dkcharles.github.io/pixl-releases/tutorials/)**, or on YouTube as the
**[Pixl Studio Overview playlist](https://www.youtube.com/playlist?list=PLWw8Drk2vUPw)**.

| | Video | What it shows |
|---|---|---|
| [![Your first Pixl game](https://img.youtube.com/vi/gAuJxbx7Lbw/mqdefault.jpg)](https://youtu.be/gAuJxbx7Lbw) | **1. [Your first Pixl game](https://youtu.be/gAuJxbx7Lbw)** (1:33) | Start blank, type a small program, fix a bug card, run it, save it and share a link. |
| [![Paint your player](https://img.youtube.com/vi/FyNs8uktf9U/mqdefault.jpg)](https://youtu.be/FyNs8uktf9U) | **2. [Paint your player](https://youtu.be/FyNs8uktf9U)** (1:59) | The Sprite editor: paint a pixel-art rocket, name it, insert it into your code, edit it in place later. |
| [![Make it walk](https://img.youtube.com/vi/lpObhPUYqZg/mqdefault.jpg)](https://youtu.be/lpObhPUYqZg) | **3. [Make it walk](https://youtu.be/lpObhPUYqZg)** (2:22) | Animation frames, the walk list and its counter, an `every` block and a `draw` line. |
| [![Add some sound](https://img.youtube.com/vi/gj1TYc-bu10/mqdefault.jpg)](https://youtu.be/gj1TYc-bu10) | **4. [Add some sound](https://youtu.be/gj1TYc-bu10)** (2:12) | The Tune editor's piano roll, `play` on a `when space` block, and the ready-made sounds. |
| [![Learn, one step at a time](https://img.youtube.com/vi/GPY_HWaoYRM/mqdefault.jpg)](https://youtu.be/GPY_HWaoYRM) | **5. [Learn, one step at a time](https://youtu.be/GPY_HWaoYRM)** (1:51) | The Learn panel: lessons beside your code, Check it, hints, the lesson path, the Reference tab. |
| [![Many things](https://img.youtube.com/vi/M5iVydA-g98/mqdefault.jpg)](https://youtu.be/M5iVydA-g98) | **6. [Many things](https://youtu.be/M5iVydA-g98)** (1:36) | The code blocks palette, a list of six rocks, `for each`, and `touches` to catch them and score. |
| [![Take it home](https://img.youtube.com/vi/yGBU5f-qOsw/mqdefault.jpg)](https://youtu.be/yGBU5f-qOsw) | **7. [Take it home](https://youtu.be/yGBU5f-qOsw)** (1:30) | My games, Save progress and Load progress, and sharing a game as a link. |

The videos use the **web Studio** at <https://dkcharles.github.io/pixl-releases/studio/>. The
Windows app works the same way; the [Studio guide](studio-guide.md) covers the few differences.
